Install Halloween Escape Map

GitHub Pages serves this app over HTTPS, so supported browsers can install it. Browser wording varies by version.

Android

Chrome / Edge: use this app's Install button when the browser offers it, or open the browser menu and choose Install app or Add to Home screen.

Samsung Internet: use the browser menu and choose its Add page to / Home screen option.

iPhone & iPad

Open the site in Safari, tap Share, choose Add to Home Screen, then tap Add.

If Add to Home Screen is not visible, scroll the Share sheet or use Edit Actions where available.

Windows & macOS

Chrome / Edge: use this app's Install button when available, the install icon in the address bar, or the browser menu's install option.

Other desktop browsers may offer different site-app or shortcut options.

When opened as the installed app, the footer Install button is hidden. If the app is later uninstalled, returning to the website lets the app re-check install availability and show the option again when the browser exposes it.
