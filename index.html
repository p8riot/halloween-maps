Quick Escape Notes

Storm Cellars

Clear boards or overgrowth if present. Unlock using an Escape Key or Bolt Cutters, as required by the entrance.

Escape Gates

Bring a Fuse and the required unlocking tool. Clear obstacles if present, then complete the exit interaction.

Civilian Sedans

Find the car, Repair Kit, Gas Can, and Sedan Key. Repair, fuel, and start it before driving to an exit.

Tower Farm Drains

Work like storm cellar escapes: clear any obstruction and unlock with the tool the game requests. Follow the on-screen prompt for the current match.

Police Escapes

Police wagons and police cars are situational escapes. Their vehicles and keys are not shown as starting map markers; see the Wiki for details.

Vehicle Exit Areas

Route markers show where a drivable escape vehicle can leave the map. They are not parked-sedan spawn points.

Customize map markers

Choose which escape routes, confirmed item sources, and optional searchable objects appear on the map.

Installable PWA

Install Halloween Companion

GitHub Pages serves this app over HTTPS, so supported browsers can install it. Browser wording varies by version.

Android

Chrome / Edge: use this app's Install button when the browser offers it, or open the browser menu and choose Install app or Add to Home screen.

Samsung Internet: use the browser menu and choose its Add page to / Home screen option.

iPhone & iPad

Open the site in Safari, tap Share, choose Add to Home Screen, then tap Add.

If Add to Home Screen is not visible, scroll the Share sheet or use Edit Actions where available.

Windows & macOS

Chrome / Edge: use this app's Install button when available, the install icon in the address bar, or the browser menu's install option.

Other desktop browsers may offer different site-app or shortcut options.

When opened as the installed app, the footer Install button is hidden. If the app is later uninstalled, returning to the website lets the app re-check install availability and show the option again when the browser exposes it.
